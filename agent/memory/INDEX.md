# Índice da memória portátil AI-memory

Fonte de verdade para continuidade entre Claude Code, Codex e outros agentes.

- `NOW.md`: estado atual compacto (abrir sempre no começo).
- `DECISIONS.md`: decisões de produto confirmadas e ADRs com razão.
- `BLOCKERS.md`: bloqueios/pendências com ação segura.
- `HANDOFF.md`: passagem de sessão/modelo sem repetir tokens.
- `HOST_INVENTORY.md`: será criado pelo agente após preflight, sem dados sensíveis.
- `../reviews/`: pareceres do Codex e revisão técnica.
- `../../docs/PRD.md`: visão funcional.
- `../../docs/BACKLOG.md`: próximas microentregas.
- `../../help/`: manuais vivos.

Política: use arquivos curtos e referências. Um fato deve ter uma fonte primária, e `NOW.md` apenas aponta. Nenhum segredo/PII/credencial entra nesta memória.
