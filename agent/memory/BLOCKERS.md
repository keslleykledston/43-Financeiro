# Pendências e bloqueios

## A confirmar sem bloquear E01–E05
- [ ] Verificar host, sudo/permissões, DNS/TLS e Nginx coexistente.
- [ ] Conectar e autorizar Lovable MCP via OAuth (opcional; UI local avança sem ele).
- [ ] Codex CLI instalado e autenticado (opcional; sem segredos nos reviews).
- [ ] Cora API para ambos CNPJs, endpoints de consulta/emissão e homologação.
- [ ] Sistema e-NF específico: API, documentação, requisitos fiscais e homologação.
- [ ] Provedor de e-mail/remetentes por CNPJ com DKIM/SPF/DMARC e consentimentos.
- [ ] Vencimento dia 31 e política de meses curtos, feriados e antecedência.
- [ ] Regras de aprovação, exceções contratuais, reajustes e proporcionalidade.
- [ ] Escolha do dono de dados e políticas de LGPD.

## Regra
Cada impedimento novo deve documentar: **evidência observável, impacto, próximo teste seguro, alternativa reversível e se exige intervenção humana**. Nunca bloquear interface DEMO por regra fiscal ainda não decidida.
