# WhatsApp: consentimento e pedido de parar

**Quem acessa:** diretoria e gerência registram e veem os consentimentos (é dado de cliente). Só a diretoria registra um pedido de parar que vale para **todas as empresas**.
**Onde:** menu **WhatsApp → Consentimentos**.

> **Regra de ouro:** sem consentimento registrado, o sistema **não envia cobrança** por WhatsApp. O pedido de **parar sempre prevalece**: nunca é desfeito sozinho e vale até alguém registrar, com prova, que o contato voltou a aceitar.

## O que registrar
- **Número do contato** (DDD + número). Aparece sempre mascarado nas listas.
- **Cliente** (opcional): só para você achar depois. O cliente precisa ser da empresa selecionada.
- **O que o contato decidiu:** *consentiu em receber avisos de cobrança* ou *pediu para não receber*.
- **Vale para:** *só esta empresa* ou, para o pedido de parar, *todas as empresas* (use quando o contato pede para não receber nada deste número, de ninguém).
- **De onde vem a prova** e **onde está a prova**: autorização verbal anotada, por escrito (e-mail, contrato), formulário ou «o cliente iniciou a conversa». Escreva só uma **referência** (ex.: «e-mail de 28/10», «contrato 123»), **nunca dado pessoal**.

## Como o sistema usa isso
- O consentimento é **por empresa**: o que o cliente aceitou da K3G Solutions **não vale** para a K3G Call.
- O estado atual do contato é o **registro mais recente**. O pedido de parar **global** do número prevalece sobre tudo, e só outro registro global (com prova) o desfaz.
- O pedido de parar vale **imediatamente**: até o envio de teste é bloqueado se o número da lista autorizada tiver pedido para parar.
- Os registros são **permanentes**: para mudar de ideia, registre um novo (o mais recente vale). Nada é apagado ou editado.
- Pedir para parar a quem já está parado (ou consentir a quem já consentiu) é recusado, para não poluir o histórico.

## Onde ver o que foi bloqueado
Em **WhatsApp → Enviar teste**, o quadro **Envios bloqueados** mostra, a cada tentativa barrada, o **motivo** (pausa, janela, limite, pedido de parar...). Nenhum número ou texto aparece ali.

## Privacidade
Cada empresa só vê os **seus** consentimentos. Um pedido de parar global aparece para as outras empresas apenas como estado do contato («pediu para parar»), **sem dizer qual empresa registrou**.
