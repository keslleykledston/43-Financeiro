# Certificado de TESTE (e2e)
`teste-e2e.pfx` é um .pfx gerado só para teste (chave RSA descartável, titular «EMPRESA TESTE LTDA:11222333000181», senha `certa-123`). Não é um certificado real nem tem valor. Serve ao e2e `e49-certificado-a1.spec.ts` (que roda sem as dependências do app). Vale ~10 anos; se vencer, gere outro com o mesmo formato.
